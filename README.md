# 🔧 Projects

## SnekMap

Network vulnerability scanner with CPE-based NVD CVE lookups and multi-threaded reconnaissance. Generates reports in JSON, CSV, and HTML formats. Tested against Metasploitable 2 with validated CVE results.

**Repository:** [github.com/synv3x/snekmap](https://github.com/synv3x/snekmap)

## Cowrie SSH Honeypot

Active SSH honeypot deployment on Raspberry Pi 4 logging brute-force attacks and attacker behavior. Fedora attack machine with Hydra-based testing and documented findings.

**Repository:** [github.com/synv3x/cowrie-honeypot](https://github.com/synv3x/cowrie-honeypot)

## Cisco Networking & Active Directory Lab

Configured enterprise networking infrastructure including subnetting, DNS, DHCP, TCP/IP, VLANs, and routing. Managed Active Directory users, groups, and system administration at scale.

## ESP32 Wireless Text Transmission

Programmed ESP32 microcontroller for wireless communication without the use of any Internet or Signals, solely based on MAC addreeses for offline communication using ESP-NOW protocol. Built real-time data transmission system between wireless devices.

## Hardware–Software Interfacing Project

Designed breadboard circuits controlled via Visual Studio using GPIO communication. Demonstrated real-time hardware-software interaction.

## Linux Server Configuration (Fedora + SELinux)

Set up hardened Fedora Linux server with SELinux enforcement. Configured firewall rules, DHCP services, and system hardening for secure administration.

## Raspberry Pi Automation & Python Scripting

Built GPIO LED circuits automated with Python scripts. Used Jupyter Notebook for testing and hosted local web server on Raspberry Pi.
